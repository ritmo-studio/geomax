# Мастера изображений

Сюда кладутся исходники от дизайнера — PNG или JPEG высокого качества
(q≥90, sRGB), по паре на кадр, где нужен отдельный мобильный:
`<блок>_<N>.png` и `<блок>_<N>_mobile.png`.

**В гит отсюда не едет ничего, кроме этого файла** (см. `.gitignore`):
мастера весят мегабайты, а нужны они только на машине, где делается
нарезка. Папка лежит вне `public/` — наружу веб-сервер её не отдаёт
даже случайно, ровно как `fonts-src` на других сайтах.

Нарезка:

    python3 tools/make-images.py img-src/objects_1.png d objects-1 public/assets/img/

`d` — десктопный мастер (320/560/1120), `m` — мобильный (480/800/1100).
Скрипт никогда не увеличивает исходник и ругается, если мастер меньше
минимума. На выходе AVIF + WebP + JPEG, имена `objects-1-d-560.webp`.

Результат (`public/assets/img/*.jpg|png|webp|avif`) тоже не коммитится:
тяжёлые медиа живут на хостинге. Порядок выкладки — в README репозитория,
раздел «Медиа».
