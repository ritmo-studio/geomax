# geomax

Сайт ГЕОМАКСа. Собирается на `ritmo-engine`: страница — PHP-файл с
инклюдами, HTML отдаёт сервер, сборка нужна только для CSS и JS.

## Что здесь

- `snapshot/` — снимок страницы, отрезанный от библиотеки
  `seo-design-system` (главная, Figma `NY7nGOBlQt9Zbos7riZKWf`,
  geomax v.0.34 SEO DS). Это **справочник, а не сборка**: фрагменты
  блоков с контентом, монолитный `sds.css`, самодостаточный
  `preview.html`. Именно эту вёрстку утвердил заказчик, поэтому при
  любом расхождении права она, а не библиотека — библиотека с момента
  отрезки ушла вперёд. Снимок не правим и в сборку не включаем.

Остальное — движок, блоки, контент и докрут — появляется следующим
коммитом, переносом снимка в формат `ritmo-engine`.

## Медиа

Растр и видео в репозитории не живут (см. `.gitignore`): они лежат на
хостинге в `public/assets/img` и `public/assets/video`, в коде стоят
пути от корня — `/assets/img/...`. Вектор (логотип, иконки) — часть
кода и коммитится; в снимке он вшит в CSS и разметку как data-URI.
